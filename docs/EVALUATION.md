# Evaluation pilot

Dataset: `evaluation/pilot.json`, 10 real PubMed MED records retrieved through Europe PMC on 2026-11-03. Each has a canonical PMID/URL, publication types, a bounded abstract excerpt, text hash, scope and retrieval provenance. There are 30 claim cases: 18 development and 12 held-out, split by source to avoid source leakage. Excerpts are bounded quotations; neither full-text retrieval nor reuse licensing beyond excerpts is asserted.

**All labels are AI-drafted and pending human review.** There is no independently reviewed gold set or expert endorsement. The current cases test passage/reference mechanics and include reviews and a retraction notice; synthetic docking, negation, cell/human, class-upgrade, malformed-output and injection regressions live separately in unit/browser fixtures. This pilot does not yet supply a balanced human-reviewed experimental/computational/conflicting benchmark.

`npm run evaluate` produces `evaluation/results.json` with dataset SHA-256, commit/date, case rows, UTF-16 spans and denominators. Mechanical results currently cover 30/30 resolvable references and 30/30 exact passages. These describe the **dataset fixtures**, not model extraction accuracy or accepted-claim precision.

Predeclared model metrics: reviewed accepted-claim support precision (supported accepted / all accepted reviewed), unsupported/overstated acceptance (such accepted / all labeled such), class confusion matrix, corrected/unchanged/rejected/unresolved outcomes, abstention/coverage (including empty runs), completion (completed / attempted), latency and reported cost with unknown costs separate. Each must show counts and percentages. Rejection of every claim cannot establish useful quality.

Paired protocol: freeze and hash source excerpts and human labels; baseline uses extraction only, two-role uses extraction plus adversarial review, both consume identical snapshots and the same source-level held-out split. Record model IDs, policy/prompt/schema versions, commit/date, per-case decisions, latency and reported cost. Single runs do not establish variance. Do not tune on held-out failures or discard failing cases.

Live baseline/two-role comparison: **blocked**, no credentials/funded model runs and no human-reviewed labels. Those metrics are null, not zero/perfect. The 90% precision target and scientific-quality claim are withheld. Offline adversarial release checks cover reference/span validity and no unsupported upgrades; hosted scientific quality remains unmeasured.

An opt-in paired harness is provided: `npm run evaluate:live`. Set `EVAL_SOURCE_ID` to a held-out source and `EVAL_MOLECULE_NAME` only after checking that source. It uses the same extraction prompt/schema and snapshot hash for both modes, makes a second extraction plus adversarial review and audit, shares one finite spend ledger across the pair, preserves partial output before/after calls, and writes ignored `.local-evaluation/` artifacts under a single-process lock. It does not publish a dossier or grade itself. This harness has not made live calls here; human matching/scoring remains necessary. Repeat per source within separately authorized caps; do not silently renew the global allowance.
