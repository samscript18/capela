## Application boundary

`OtariGatewayService` is the server-side adapter for `https://otari.ai/api/v1`. Default research uses hosted Otari; missing keys never activate direct providers. PubChem/NCBI identity is authoritative external data and earns no Otari tool credit. The opt-in direct Vertex review path is hybrid, separately billed and excluded from the qualifying attempt. Legacy Gemini/Groq/Tavily details are archived in [LEGACY_ARCHITECTURE.md](LEGACY_ARCHITECTURE.md).
